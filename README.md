# Cascarino’s Whitestone

A complete, buildless-first redesign for the Whitestone restaurant at 152-59 10th Avenue.

## Run and build

- `npm run build`: copies the deployable files to `dist/`. No dependencies or install required.
- `npm test`: structural and content checks.
- Static entry: `index.html`. Vercel is configured for `dist/`.

## Experience

Cream and pizzeria red, two locally served photos, and a scroll-controlled oven shutter. The effect is decorative; readers who use reduced motion, disable scripts, or have a short screen see the photo without pinning. The separate menu keeps category links and a local search.

No payment or order is taken by this site. Order actions go to the restaurant’s existing Toast storefront. No fabricated booking/contact forms. No invented testimonials or ratings.
